# Radiance Cascades в сравнении со стандартными методами глобального освещения в Unity

Экспериментальные данные и результаты сравнения производительности для научной работы **«Сравнительная оценка методов глобального освещения в реальном времени в Unity URP»**, подготовленной в рамках исследовательского проекта для конференции DiGRA.

## Обзор

Глобальное освещение (Global Illumination, GI) — важнейшая технология в рендеринге реального времени, позволяющая свету взаимодействовать с поверхностями и создавать более реалистичные и визуально целостные пространства.

Однако различные методы GI требуют разного объема вычислительных ресурсов, поэтому выбор подходящего способа рендеринга критически важен для приложений реального времени и видеоигр.

В этом репозитории представлены результаты экспериментальных измерений и материалы для сравнения технологии **Radiance Cascades** с другими конфигурациями глобального освещения в составе Universal Render Pipeline (URP) движка Unity.

Эксперименты направлены на оценку производительности рендеринга в сценах различных типов и с разной визуальной стилистикой.

## Цели исследования

Основные цели данной работы:

- Сравнить производительность различных конфигураций глобального освещения в Unity.
- Оценить вычислительные затраты на использование Radiance Cascades по сравнению с альтернативными подходами.
- Проанализировать показатели частоты кадров (FPS) и времени отрисовки кадра (frame time).
- Исследовать влияние характеристик сцены на производительность рендеринга.
- Предоставить экспериментальные данные для дальнейшего анализа и обеспечения воспроизводимости результатов.

## Сравниваемые конфигурации рендеринга

Наборы экспериментальных данных включают измерения для четырех конфигураций рендеринга:

| Конфигурация                     | Идентификатор набора данных | Описание                                                 |
| -------------------------------- | -------------------------- | --------------------------------------------------------- |
| Без глобального освещения        | `NoGI`                     | Базовая конфигурация рендеринга без использования GI      |
| Radiance Cascades                | `RC`                       | Метод глобального освещения на основе каскадов яркости (radiance cascades) |
| Освещение в реальном времени     | `RTLM`                     | Конфигурация освещения в реальном времени, использованная в экспериментах |
| Глобальное освещение в экранном пространстве | `SSGI`         | Метод оценки непрямого освещения в экранном пространстве (screen space) |

Эти конфигурации оцениваются на различных типах сцен для выявления различий в производительности рендеринга.

## Экспериментальные сцены

В измерениях представлены сцены трех категорий.

### 1. Изометрическая сцена

Изометрическое окружение, используемое для анализа производительности рендеринга в сцене с изометрической проекцией. ### 2. Реалистичная сцена

### Организация набора данных

В каждой директории, соответствующей экспериментальной сцене, содержатся:

- **CSV-файлы:** «Сырые» данные измерений, собранные в ходе отдельных запусков процесса рендеринга.
- **Файлы Excel:** Таблицы со сравнением производительности для соответствующей сцены.
- **Директории Unity:** Дополнительные материалы, относящиеся к эксперименту (если имеются).

Имена CSV-файлов формируются по следующему принципу:

```text
gi_run_<МЕТОД>_<ДАТА>_<ВРЕМЯ>.csv
```

Пример:

```text
gi_run_RC_2026-02-19_16-02-12.csv
```

Идентификатор метода указывает на конфигурацию рендеринга, использовавшуюся при проведении измерений.

## Показатели производительности

В исследовании основное внимание уделяется двум ключевым показателям производительности.

### Количество кадров в секунду (FPS)

FPS (Frames Per Second) — это число кадров, отрисовываемых за одну секунду.

Более высокий показатель FPS, как правило, свидетельствует о более высокой пропускной способности системы рендеринга.

### Время отрисовки кадра (Frame Time)

Время отрисовки кадра — это время, затрачиваемое на рендеринг одного кадра; обычно измеряется в миллисекундах.

Меньшее время отрисовки кадра, как правило, указывает на более высокую производительность рендеринга. Взаимосвязь между FPS и временем кадра (frame time) выражается следующей приблизительной формулой:

\[
\text{Время кадра (мс)} = \frac{1000}{\text{FPS}}
\]

Оба показателя позволяют оценить вычислительные требования и характеристики производительности тестируемых конфигураций рендеринга.
